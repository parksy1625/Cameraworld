# 촬영 가이드

COLMAP SfM이 성공하려면 충분한 각도 다양성과 프레임 간 겹침이 필요하다. 다음을 지키면 실패율이 급감한다.

## 필수

1. **대상을 돌면서 촬영**. 한 자리에서 회전(pan)만 하면 시차가 없어 재구성이 어긋난다.
2. **프레임 간 70% 이상 겹침**. 앱의 가이드 링이 8개 슬라이스를 채우도록 360°를 돈다.
3. **움직이는 피사체 피하기**. 차량, 사람, 흔들리는 나무는 특징 정합을 망가뜨린다.
4. **고른 조명**. 강한 역광·반사(유리, 물)는 매칭 실패 원인.
5. **텍스처가 있는 표면**. 단색 벽만 있는 장면은 특징점이 부족.
6. **GPS 켜기**. 1차 지오참조는 EXIF GPS만 사용.

## 권장

- 영상: 1080p, 30fps, 4K 이상이면 서버에서 리사이즈됨.
- 사진: 2~6메가픽셀. 너무 고해상도는 저장만 차지.
- 최소 20장 / 2분 영상 / 20~60초 걸으며 360°.
- 높이를 2단(눈 높이 + 허리 높이)로 바꿔가며 2바퀴.

## 금지

- 반사·투명 대상 (거울, 창문, 수면)
- HDR/Portrait 모드 (비선형 톤매핑으로 매칭 실패)
- 플래시 (조명 변화 커짐)
